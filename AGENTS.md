## Project rules

- This folder is the repo and the live site: everything committed is public on audiolyte.be,
  this file included. No internal numbers, plans, client data or secrets here.
- Deploy is a push to `main` (GitHub Pages, branch based). Never add an Actions Pages workflow.
- `index.html` and `producten.html` render with React through `support.js`. The block between
  `prerender:start` and `prerender:end` is generated by `prerender.py`: never edit it by hand.
- `support.js` is a generated file with local patches, listed in its first line. After a change
  to it, bump `support.js?v=` on both pages.
- `vendor/*.js` must stay byte-exact (SRI hashes in `support.js`); `.gitattributes` guards this.
- Never hide text from visitors (1px, clipped, off-screen, `aria-hidden` copy). Google treats it as spam.
- No em dashes in site copy. Keep the FAQPage JSON-LD in sync with the visible Dutch FAQ.
- Decisions, with dates and rejected options, live in `README.md` under "Beslissingen".
